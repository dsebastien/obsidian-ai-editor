## Adversarial code-review fixes (same day)

Ten confirmed blocker/major findings from three adversarial reviewers, all fixed:

- **Late-finding remap (blocker)**: `ReviewRunHandle` now records every `applyTextChanges` batch and replays the history onto findings that arrive after the user edited — a late finding is remapped to current coordinates or marked stale, never left on snapshot offsets (BR #3/#4).
- **Anchor boundary off-by-one**: `mapAnchorThroughChange` uses inclusive boundary comparisons — deletions/replacements merely touching an anchor boundary shift/no-op instead of wrongly staling the finding.
- **Occurrence semantics**: `matchQuote` resolves `occurrence` against ALL document occurrences (contract definition), with prefix/suffix hints as an independent corroboration check; occurrence/hint disagreement → ambiguous (display-only), never a guessed anchor.
- **Settings salvage granularity**: `loadSettingsDetailed` salvages per entity (array elements, behavior fields) instead of per section — one corrupt backend no longer wipes all API keys, one corrupt scalar no longer resets privacy exclusions (BR #7). Dropped paths are reported; `bootstrapSettings` passes them up and the plugin shows a Notice.
- **Exclusions fail closed**: `isExcluded` with null metadata treats the note as excluded when tag exclusions are configured or the frontmatter opt-out is respected (cold-cache window no longer leaks `#private` notes). Folder matching is now case-insensitive (case-insensitive filesystems).
- **Excluded review target**: `assembleContext` structurally rejects an excluded target with typed `ExcludedTargetError` — no longer dependent on call-site pre-checks.
- **Error redaction seam**: `RunEditorSpec.redactError` — the run controller routes every outbound error message (thrown + error events) through it so provider 401 bodies echoing API keys never reach `EditorRunState.error` (BR #12).
- **Write/read symmetry**: `AIEditorPlugin.update` and the fallback facade validate the produced settings against the schema before `saveData` (reject + keep previous on failure); the rules-tab match-value input skips committing empty values; chip lists surface rejected saves via Notice.

New/updated specs across anchor, match, run-controller, settings-schema, settings-facade, exclusions, and context-assembler (440 tests total, green). tsc/lint/build green.
